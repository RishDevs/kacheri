Judgment

Guilty on Count 1. Counts 2 to 4 dismissed for want of evidence.

In plain words: this change breaks one thing, proven by a test that fails. The other three concerns had no working proof, so they are not counted. A fix has been tested and is ready.

I. The Charges

  1. Count 1. Hostnames with a port lose their protocol. index.js:17 PROVEN
  2. Count 2. Trailing dots in hostnames may be dropped. DISMISSED
  3. Count 3. Query parameters are sorted differently. DISMISSED
  4. Count 4. Unicode hostnames are not converted. DISMISSED

II. The Evidence on Count 1

The prosecution (Nemotron Nano) filed a test as its proof. The court ran it three times on the code before the change, three times after, and three times with the fix.

Run 1Run 2Run 3 Before the changePASSPASSPASS After the changeFAILFAILFAIL With the fixPASSPASSPASS

import { test } from 'node:test';
import assert from 'node:assert/strict';
import normalizeUrl from '../index.js';

test('keeps http:// for a host with a port', () => {
  assert.equal(normalizeUrl('sindresorhus.com:123'), 'http://sindresorhus.com:123');

EXHIBIT 3The line at issue, index.js
  return protocol.endsWith(':')
    && !protocol.includes('.')     ← removed by this change
    && !supportedProtocols.has(protocol);

III. The Defense

Counsel for the change (Nemotron Super) conceded Count 1: hostnames with a port are documented input, and nothing in the pull request says this behaviour should change.

IV. Findings of the Court

On Count 1: the test is sound, it fails only after the change, and the failure traces to the removed check at line 17. The change was presented as a refactor. The charge is proven.

On Counts 2 to 4: dismissed without trial. Count 2’s test passed on the new code. Count 3’s test gave the same result before the change. Count 4’s test could not run.

V. Order

It is ordered that the following remedy be applied. The court re-ran Exhibit 1 on the remedied code (3 of 3 pass) and the library’s own 25 tests (all pass).

  return protocol.endsWith(':')
+   && !protocol.includes('.')
    && !supportedProtocols.has(protocol);

So ordered.
