Proven bug

Hosts with a port lose their protocol

normalizeUrl('sindresorhus.com:123') used to return http://sindresorhus.com:123. After this change it returns the input unchanged, because sindresorhus.com: is now mistaken for a custom protocol.

index.js, line 17
