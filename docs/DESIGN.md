# Kacheri: visual design (binding)

Source of truth: `docs/design/Main.dc.html` (Judgment = case view) and `docs/design/Bench.dc.html` (Court record = benchmark), from the Claude Design canvas https://claude.ai/artifact/8P2jGggwzTWJ4ZZKDZvZoD. Reproduce them exactly (copy style, type, spacing, colours). Ignore the `<x-dc>`, `{{ }}` and script wrapper (canvas runtime).

Direction: a real court filing, not courtroom clip-art. Pleading paper (line-number margin + double red rule), case caption (Plaintiff v. Defendant with the `)` column, Case No., JUDGMENT), Roman-numeral sections (I. The Charges, II. The Evidence, III. The Defense, IV. Findings of the Court, V. Order), exhibit labels, Courier for exhibits and numbers (court-transcript convention), a signature line "Nemotron 3 Ultra, presiding". Every legal phrase is followed by plain language: the judgment box always has "In plain words:".

- Fonts: Libre Caslon Text (document), Courier Prime (exhibits, code, numbers, SHAs), Inter Tight 500/600 (UI chrome, buttons, small labels). Google Fonts.
- Colours: page #EFEDE6, paper #FBFAF6, ink #1B1B1B, secondary #3B3A36 / #5B5A54, dismissed #77756D, rules #D8D4C8, margin rule #E3C9C9, exhibit bg #F3F1EA, header bar #1B1B1B. PASS #1D3F8F (navy ink). FAIL / guilty #A51C1C (red ink). Nothing else. Light only.
- Mapping from CaseRecord: Plaintiff = "THE MAINTAINERS OF <REPO>", Defendant = "PULL REQUEST <short head sha>, “<title>,”"; Case No. from case id; counts = charges in order; Count status PROVEN (convicted) / DISMISSED; Section II per convicted count: Exhibit 1 trial-run record (Before / After / With the fix × Run 1-3, With-fix row only when remedy exists), Exhibit 2 witness code, Exhibit 3 the diff lines at the charged location; III defense text per convicted count (concedes → "conceded", else "argued"); IV judge reasons for convicted + one plain sentence per dismissed count (reasons: passes on head → "its test passed on the new code"; fails on base → "its test gave the same result before the change"; broken/error → "its test could not run"; flaky → "its test was not consistent"; lint → "its test checked the wrong thing"; sandbox → "its test tried something not allowed"; judge dismissed → judge reason); V Order = remedy patch + verification sentence, or "No remedy is ordered." when none / not verified (say so plainly); costs and time from usage.
- No convictions: judgment "Not guilty. All N counts dismissed for want of evidence." + plain words "Nothing in this change was proven to break."
- Live case in progress: the judgment box shows the current stage in plain words ("The prosecution is writing proof tests…", "The court is running test 7 of 24…", "The defense is responding…", "The judge is deciding…", "The court is testing the fix…"); sections fill in as events arrive. No spinners, no animation.
- Docket (case list) = a plain table: Case No., parties (PR title), filed, judgment (GUILTY n / NOT GUILTY), costs.
- Banned: gradients, shadows, glow, blur, emoji, gavel/scales icons, stamps, animation, dark theme, cards grids, "AI-powered".
